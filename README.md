# lib-libz

sdkgen-generated zlib FFI bindings — generic ports plus the
`c-linux-x86_64` adapters, emitted under `handl-packages/generated/` (a
gitignored build artifact).

## Layout

```text
src/        the .hnl sources
specs/      committed sdkgen inputs (libz.sdkgen.yaml)
handl-packages/generated/   build artifact — regenerated by the gate
pkg.hnl     package manifest — modules, deps, description, license
```

## Regenerate

```bash
hnl sdkgen c /usr/include/zlib.h \
  --output handl-packages/generated/libz \
  --config specs/libz.sdkgen.yaml
```

(needs libclang — set `LIBCLANG_PATH` if the loader cannot find it)

## Gate

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```

The gate regenerates `handl-packages/generated/` from `specs/` first, then
typechecks/lints/tests whatever `.hnl` sources exist.
